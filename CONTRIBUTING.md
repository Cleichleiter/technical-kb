# Contributing

## Standards
- Use clear, direct language.
- Prefer step-by-step procedures for SOPs.
- Include prerequisites, validation steps, and caveats.
- Avoid sensitive data (credentials, client identifiers, internal IPs).

## Filenames
Use kebab-case and descriptive names (e.g., robocopy-multithreaded-file-replication.md).

## Templates
Start new documents from:
- templates/kb-article-template.md
- templates/sop-template.md
